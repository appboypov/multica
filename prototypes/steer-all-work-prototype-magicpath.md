# Steer all work prototype (MagicPath)

Source: [Steer all work prototype on MagicPath](https://designs.magicpath.ai/v1/calm-water-3032)

Source code: [prototypes/web](https://github.com/appboypov/multica/tree/main/prototypes/web), merged in [PR #7](https://github.com/appboypov/multica/pull/7) as `7c09e70ab`; [PR #10](https://github.com/appboypov/multica/pull/10) adds the Organisations, Worklanes and Releases pages, removes squads and fixes the worklane data and a release's ship date (MagicPath revision 460535099583266816). [PR #44](https://github.com/appboypov/multica/pull/44), open, brings the New issue dialog and the issue page in line with [PR #42](https://github.com/appboypov/multica/pull/42): a Markdown toggle and a copy button on the description, and a hand edit in the Markdown locks the fields; the hosted build is its MagicPath revision 461264854846701568. MagicPath component `460347227076988928`.

## What it shows

The clickable prototype of the "steer all work" design, light mode only, built on [Steer all work screens (steer-all-work.pen)](../designs/screens/steer-all-work.md) and [Multica component library (multica.lib.pen)](../designs/systems/multica.lib.md). Brian can click through Projects, a Project, a worklane's release timeline and Board view, the Organisations page and an organisation's projects, the Worklanes and Releases pages, and a new issue from a template, and run the creation flows: add a repository, make a worklane, plan a release, edit and move a release under the version rules, and make issues of every template type. Squads stay as Multica has them and open a placeholder.
