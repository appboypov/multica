与你有关的内容分布在侧边栏的两个页面：

- **收件箱**列出你的待办，也就是等你处理的事。它的数字是你未完成待办的数量。
- **动态**列出你关注的任务的消息，也就是不需要你做什么的变化和评论。它没有数字。

两者都不是完整的活动日志；完整上下文仍然保存在对应的任务中。

## 收件箱的内容

每条待办占一行，同一任务上有多条时也各占一行。逾期的待办排在最前，其余按从新到旧排列。待办处理后会自行离开：

| 待办 | 何时出现 | 何时离开 |
|---|---|---|
| **给你的问题**、**给你的审批** | 有人向你提问或请你审批 | 你作答、问题不再开放，或问题被重新分配给别人 |
| **提到了你** | 有人在任务描述或评论中 @你，包括通过 `@all` 或 `@squad` | 你在这条任务上发表任意评论 |
| **分配给你** | 分配给你的任务处于 `todo`、`back_from_qa`、`blocked` 或 `in_review` | 任务进入其他状态或换了负责人 |
| **等待你的评审** | 你创建的任务进入 `in_review`，且你不是负责人 | 任务离开 `in_review` |
| **智能体受阻** | 在为你工作的执行中，智能体把任务改为 `blocked` | 任务不再是 `blocked`，或智能体在该任务上再次执行 |
| **运行失败** | 为你工作的智能体执行失败 | 智能体在该任务上再次执行 |
| **自动驾驶已暂停**、**已达配额上限**、**快速创建失败** | 自动化因失败被暂停或达到配额上限，或快速创建失败 | 自动化被恢复、自动化执行再次被接受，或重试成功创建了任务 |

如果一条处于 `in_review` 的任务上还有给你的未答问题（例如合并审批），收件箱只显示这个问题。

## 处理待办

选择一条待办，它会在右侧打开。标题下的一行说明它在什么情况下离开，正文可以让你就地处理：回答问题、回复提及、修改状态或恢复自动化。

**标记为完成**位于悬停的行上和打开的待办顶部。它会立即移除这条待办，并减少收件箱的数字，但不会改动任务本身。之后发生的事件（例如新的提及）会产生新的待办。

收件箱没有已读状态，也没有"已归档"列表：其中的每一行都还在等你。没有未完成的待办时，它会显示**没有等你处理的事**，并提供**打开更新**。

## 动态的内容

常见通知包括：

- 任务分配给你，或从你名下移走；
- 你订阅的任务出现新评论，或负责人、状态、优先级和日期发生变化；
- 你创建的任务或评论收到表情回应；
- 通过智能体创建任务的操作完成；
- 你订阅的自动化创建了新任务。

问题、提及、执行失败、自动化暂停、配额上限和快速创建失败是收件箱中的待办，而不是动态中的通知。

自己的操作不会通知自己。同一任务的多条通知会合并成一项，打开后可查看这条任务最近的变化。

## 自动订阅的来源

订阅一条任务后，它的消息会进入你的动态。以下参与者会自动订阅任务：

- 任务的创建者；
- 新的负责人；
- 发表评论的人；
- 在任务描述中被新增 @提及的人；
- 自动化中预先配置的订阅成员。

负责人变更不会取消原有订阅。可以在任务页面随时订阅或取消；取消后普通更新不再进入动态，直接 @你仍会在收件箱中产生待办。

<Callout type="info">
子任务的状态发生变化时，父任务的订阅者也会在动态中收到通知。子任务的评论、优先级和日期变化不会向父任务冒泡。
</Callout>

## 智能体不使用收件箱

收件箱和动态只面向工作区成员。即使智能体是负责人或订阅者，它也不会收到待办或通知。

在评论中 @智能体、把任务分配给智能体或触发自动化，都会直接创建一次执行，而不是给智能体留一条待办。`@all` 也只为成员产生待办。

## 在动态中处理通知

选择一条通知会把它标为已读。处理完后可以归档；归档不会修改或删除对应的任务。

右键点击一条通知，可以使用**标为已读** / **标为未读**和**归档**（在"已归档"视图中是**取消归档**）。标为未读表达的是"我看过了，但还没处理完"：该通知重新变为未读；即使它还开着也会保持未读——之后再打开一次才会照常标为已读。已归档的通知会保留已读状态，因此恢复时会原样回来。

动态菜单还可以：

- 全部标为已读；
- 归档全部或全部已读；
- 归档状态为 `done` 或 `cancelled` 的任务通知；
- 打开"已归档"并恢复某条通知。

从动态底部打开**已归档**，向下滚动可继续加载更早的通知。筛选覆盖全部归档记录，包括尚未加载的记录。

## 调整通知类型

打开**设置 → 通知**，可以分别开关以下各组动态通知：

- 分配；
- 状态变更；
- 评论；
- 优先级与日期。

关闭某一类后，相关变化仍然保存在任务中，只是不再在动态中创建通知。待办不受这些设置影响：问题、提及和执行失败总会进入收件箱。表情回应、已完成的快速创建和自动化创建的任务等少数类型不受这四组控制，始终投递。系统通知和浏览器通知控制待办和通知两者的桌面横幅：点击横幅会在收件箱中打开待办，或在动态中打开通知。它们不会改变任何一个列表。
