あなたに関係するものは、サイドバーの 2 つのページに分かれています。

- **インボックス**には ToDo、つまりあなたの対応を待つものが並びます。数字は未完了の ToDo の数です。
- **アップデート**には、フォロー中のタスクの動き、つまりあなたに何も求めない変更やコメントが並びます。数字はありません。

どちらも完全なアクティビティログではありません。完全なコンテキストは対応するタスクに残ります。

## インボックスに届くもの

ToDo は 1 件ごとに 1 行で、同じタスクに複数あってもそれぞれ 1 行です。期限を過ぎた ToDo が先頭に、そのあとは新しい順に並びます。ToDo は対応が済むと自動的に消えます。

| ToDo | 届くとき | 消えるとき |
|---|---|---|
| **あなたへの質問**、**あなたへの承認依頼** | 誰かがあなたに質問または承認を求めたとき | 回答したとき、質問が開いていなくなったとき、または別の人に再割り当てされたとき |
| **あなたをメンション** | 誰かがタスクの説明やコメントであなたを @メンションしたとき（`@all` と `@squad` を含む） | そのタスクにあなたがコメントを投稿したとき |
| **あなたに割り当て** | あなたが担当のタスクが `todo`、`back_from_qa`、`blocked`、`in_review` のいずれかにあるとき | タスクが別のステータスまたは別の担当者に移ったとき |
| **あなたのレビュー待ち** | あなたが作成したタスクが `in_review` になり、あなたが担当者ではないとき | タスクが `in_review` を離れたとき |
| **エージェントがブロック中** | あなたのために動く実行の中で、エージェントがタスクを `blocked` にしたとき | タスクが `blocked` でなくなったとき、またはエージェントがそのタスクで再び実行されたとき |
| **実行に失敗** | あなたのために動くエージェントの実行が失敗したとき | エージェントがそのタスクで再び実行されたとき |
| **オートパイロット一時停止**、**クォータ上限に到達**、**クイック作成に失敗** | オートパイロットが失敗により一時停止したかクォータ上限に達したとき、またはクイック作成が失敗したとき | オートパイロットが再開されたとき、オートパイロットの実行が再び受け付けられたとき、または再試行でタスクが作成されたとき |

`in_review` のタスクにあなた宛ての未回答の質問（マージの承認など）もある場合、インボックスには質問だけが表示されます。

## ToDo の処理

ToDo を選択すると右側に開きます。タイトルの下の 1 行が、その ToDo が消える条件を示します。本文ではその場で対応できます。質問に回答する、メンションに返信する、ステータスを変える、オートパイロットを再開する、といった操作です。

**完了にする**は、ホバーした行と開いた ToDo の上部にあります。ToDo をすぐに取り除き、インボックスの数字を減らします。タスク自体は変わりません。新しいメンションなど、あとで起きた出来事は新しい ToDo を作ります。

インボックスには既読状態も「アーカイブ済み」もありません。並んでいる行はすべて、まだあなたを待っています。未完了の ToDo がないときは **対応待ちはありません** と表示され、**更新を開く** が出ます。

## アップデートに届くもの

主な通知は次のとおりです。

- タスクがあなたに割り当てられた、またはあなたから外された
- 購読中のタスクに新しいコメントが付いた、または担当者・ステータス・優先度・日付が変わった
- あなたが作成したタスクやコメントにリアクションが付いた
- エージェント経由のタスク作成が完了した
- 購読中のオートパイロットが新しいタスクを作成した

質問、メンション、実行の失敗、オートパイロットの一時停止、クォータ上限、クイック作成の失敗は、アップデートの通知ではなくインボックスの ToDo になります。

自分の操作は自分には通知されません。同じタスクの複数の通知は 1 件にまとめられ、開くとそのタスクの最近の変化を確認できます。

## 自動購読の発生源

タスクを購読すると、その動きがアップデートに届きます。次の関係者はタスクを自動的に購読します。

- タスクの作成者
- 新しい担当者
- コメントした人
- タスクの説明で新たに @メンションされた人
- オートパイロットで事前設定された購読メンバー

担当者が変わっても、既存の購読は解除されません。タスクのページでいつでも購読・購読解除できます。購読解除後は通常の更新はアップデートに届かなくなりますが、あなたへの直接の @メンションは引き続きインボックスの ToDo になります。

<Callout type="info">
サブタスクのステータスが変わると、親タスクの購読者のアップデートにも通知が届きます。サブタスクのコメント、優先度、日付の変更は親タスクには伝わりません。
</Callout>

## エージェントはインボックスを使わない

インボックスとアップデートはワークスペースメンバー専用です。エージェントが担当者や購読者であっても、ToDo や通知を受け取ることはありません。

コメントでの @メンション、タスクの割り当て、オートパイロットのトリガーは、エージェントに ToDo を残すのではなく、直接実行を作成します。`@all` も ToDo をメンバーにのみ作ります。

## アップデートでの通知の処理

通知を選択すると既読になります。対応が済んだらアーカイブできます。アーカイブしても対応するタスクは変更・削除されません。

通知を右クリックすると、**既読にする** / **未読にする**と**アーカイブ**（「アーカイブ済み」ビューでは**アーカイブ解除**）を使えます。未読にするは「目は通したが、まだ終わっていない」ための操作です。通知は未読に戻り、開いたままでも未読のままで、あとでもう一度開けば通常どおり既読になります。アーカイブ済みの通知は既読状態を保持するため、復元すると元のまま戻ります。

アップデートのメニューからは次の操作もできます。

- すべて既読にする
- すべてアーカイブする、または既読の項目をすべてアーカイブする
- `done` または `cancelled` のタスクの通知をアーカイブする
- 「アーカイブ済み」を開いて通知を復元する

アップデート下部の**アーカイブ済み**を開くと、スクロールに合わせて過去の通知が読み込まれます。フィルターは、まだ読み込まれていない通知も含め、アーカイブ全体に適用されます。

## 通知タイプの調整

**設定 → 通知**では、アップデートの通知を次のグループごとにオン・オフできます。

- 担当の割り当て
- ステータス変更
- コメント
- メンション
- 優先度と期限
- エージェントのアクティビティ

グループをオフにしても、関連する変更はタスクに記録され続けます。アップデートの通知が作られなくなるだけです。ToDo はこの設定の影響を受けません。質問、メンション、実行の失敗は常にインボックスに届きます。リアクション、完了したクイック作成、オートパイロットが作成したタスクなど一部のタイプはこの 6 グループの対象外で、常に届きます。システム通知とブラウザ通知は、ToDo と通知の両方についてデスクトップのバナーを制御します。バナーをクリックすると、ToDo はインボックスで、通知はアップデートで開きます。どちらのリストも変わりません。
